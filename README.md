# 學長的工具箱 SenPaiToolBox（Blender Add-on）

提供貼圖收集、材質改名、Alembic 烘焙、FBX 動畫導出及 Flipbook 生成五項工具。

- 程式版本：v1.8（bl_info 為 1.8；Git 標籤為 v1.8.0）。
- 文件更新日期：2026-10-22。
- 檢查基準：主程式 commit cec3787；主程式與 v1.8.0 標籤內容相同。
- 本次只更新說明文件，未修正下列已知問題。

## 使用前注意

請先備份 .blend 與來源素材，並在副本上確認結果。貼圖收集會覆蓋目的端同名檔案，並自動儲存目前 .blend；動畫工具也會改動場景資料。不要把操作完成訊息當作輸出正確性的保證，請檢查實際檔案與播放結果。

## 系統需求與驗證範圍

套件宣告最低 Blender 版本為 4.0.0。主程式在載入時會匯入 NumPy；若匯入失敗，整個套件會無法載入，不只影響 Flipbook。

2026-10-22 在 Windows 上，以獨立背景程序及 factory-startup、disable-autoexec 參數完成以下檢查：

- Blender 4.0.2：主程式載入通過；註冊／解除註冊連續兩輪通過。
- Blender 4.5.8 LTS：主程式載入通過；註冊／解除註冊連續兩輪通過。
- Blender 5.2.0 LTS：主程式載入通過；註冊／解除註冊連續兩輪通過。
- 每個版本均檢查 6 個類別及 9 個 Scene 屬性正常建立、移除。
- Blender 4.0.2 啟動時有安裝目錄內其他腳本的警告，該環境不是完全純淨環境。

以上僅證明上述環境中的載入與註冊生命週期通過，不代表五項功能、介面操作或所有 Blender 4.x／5.x 版本均已驗證。

目前未建立自動測試套件或 CI。五項功能的完整場景測試、輸出驗證、異常復原及大型影像記憶體測試仍待完成。

## 安裝與開啟

1. 取得本倉庫的 SenPai_toolbox.py。
2. 開啟 Blender 的 Edit > Preferences，使用外掛檔案安裝功能選取此 .py 檔；安裝入口名稱與位置可能依版本不同。
3. 在 Add-ons 中搜尋並啟用「學長的工具箱 SenPaiToolBox」。
4. 回到 3D Viewport，按 N 開啟側邊欄，選擇「學長的工具箱 SenPaiToolBox」分頁。

上述為使用流程說明；本次背景測試未驗證 Preferences 安裝流程或側邊欄的實際顯示。

## 五項功能與目前限制

### 1. 貼圖收集（Pack Textures）

掃描所有材質節點樹第一層的 Image Texture 節點，將外部單張貼圖或序列圖複製到 .blend 旁的 Textures 資料夾，並更新 Image 路徑。此功能是外部檔案收集，不是 Blender 的內嵌 Pack。

- 使用前必須先儲存 .blend。
- 單張貼圖放入 Textures/_Single_Textures；序列圖依節點名稱或標籤建立資料夾。
- 不會遞迴掃描節點群組內部，也未實作 packed 貼圖的自動解包。
- 不同來源的同名單張貼圖會互相覆蓋，可能讓不同 Image 指向同一份錯誤內容。
- 共用同一 Image 的多個節點會重複處理；序列辨識只比對檔名前綴與副檔名，可能收進非該序列的檔案。
- 複製錯誤會被略過，完成訊息不保證所有貼圖都成功收集。
- 最後會呼叫全檔案路徑相對化，並自動儲存目前 .blend；影響不只限於本次成功複製的貼圖。

### 2. 材質改名（Rename Materials）

將選取網格物件各材質槽所引用的材質，改名為該物件名稱。

- 直接修改共用材質資料，不會先複製成獨立材質。
- 若多個物件共用材質，未選取物件所看到的材質名稱也會改變。
- 同一材質被多個選取物件引用時，最終名稱受處理順序影響；名稱衝突時也可能出現數字後綴。
- 回報數量是處理的材質槽次數，不一定是不同材質的數量。

### 3. Alembic 快取轉 Shape Keys（ABC to ShapeKeys）

針對選取且帶有 Mesh Sequence Cache 修改器的網格，依場景起訖幀逐幀建立 Shape Keys 與關鍵幀。目前步長固定為 1，介面沒有隔幀設定。

- 插入關鍵幀前暫時將全域預設插值設為 Constant，並在 finally 區塊還原；這不構成避免所有 API 錯誤或崩潰的保證。
- 會刪除既有名稱為 Basis 或以 ABC_Frame_ 開頭的 Shape Keys，請先備份。
- 未檢查各幀頂點數及頂點對應關係；拓樸改變可能造成錯誤或不正確結果。
- 暫存網格由 evaluated object 建立，但清理呼叫使用原始物件，仍需修正。
- 中途失敗可能留下部分烘焙資料，且目前幀未必恢復。
- 烘焙後預設不會停用快取修改器；尚不能保證移除外部快取後可獨立播放。

### 4. 多 Action 導出 FBX（Export FBX Actions）

輸入骨架名稱及輸出目錄後，程式會選取指定物件與其直接子層網格，輪流指定 Actions 並輸出個別 FBX。

- 實際遍歷的是整份 .blend 的所有 Actions，未篩選哪些動畫適用於指定骨架。
- 目前僅檢查物件名稱存在，沒有確認其類型確實為骨架。
- 未明確選擇或驗證 Action slot；多 slot 與不相容 Action 情境仍待實測，不能保證動畫精確隔離。
- 不會完整恢復選取狀態、Active Object 或場景起訖幀；原始 Action 只在正常結束時還原。
- 使用目標物件實際需要的動畫資料副本測試，並逐一檢查導出結果。

### 5. 序列圖轉 Flipbook（Sequence to Flipbook）

讀取來源資料夾第一層的 PNG、JPG、JPEG、TIF、TIFF、EXR 副檔名項目，依自然排序排列，將每張圖縮放為指定正方形尺寸，再輸出 PNG 網格圖。

- 來源圖片若非正方形，縮放會改變長寬比例。
- 修改來源路徑時會重新計數；不會持續監看資料夾。此計數只依副檔名，不代表影像已成功解碼。
- 介面依快取數量檢查「欄數 × 列數」容量；資料夾後續新增圖片可能繞過檢查，生成時超出容量的圖片會直接截斷。
- 載入失敗的圖片會被跳過，對應格子留空，最後仍可能回報成功。
- 沒有畫布記憶體上限；高解析度或大量格數可能耗用大量記憶體。
- RGB：已填入格子的 RGB 不變，Alpha 設為 1；不會自行產生邊緣擴張。
- RGB + 黑底：已填入格子的 RGB 乘上 Alpha，再將 Alpha 設為 1。
- RGBA：保留讀入、縮放後的 Alpha。
- 所有模式的未填入格子都保留初始化的透明黑；RGB 模式名稱不代表 PNG 一定不含 Alpha 通道。

## 共通錯誤處理限制

多個 Operator 在回報 ERROR 後仍回傳 FINISHED，部分檔案錯誤也會被略過。成功或完成訊息不代表所有輸入都已正確處理；若結果不完整，請保留錯誤訊息與可重現的測試副本。
